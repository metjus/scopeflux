Why there is no Google search data

Google does not publish search volume. The official Trends API is limited to approved partners, and scraping the public pages breaks Google's terms and stops working without warning. ScopeFlux uses the public daily trending feed where it can, and measures interest where the data is genuinely open.

What ScopeFlux keeps

A daily snapshot of what every source reported, since 2 Sep 2026. It is how topic pages can say when something first appeared and how long it lasted.
